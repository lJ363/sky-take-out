# sky-take-out

校园场景的外卖点餐平台（学习项目）。后端是 Spring Boot 多模块单体应用，配套后台管理页与微信小程序顾客端。

> 当前状态：day01 环境搭建完成，业务功能开发中。本文件随项目进度更新。

## 项目定位

- 三个实践项目中的第一个：目标是打通 Java 后端工程基本功，并在真实开发节奏中熟练使用 git / GitHub。
- 业务上覆盖后台的员工、分类、菜品、套餐、订单管理，以及顾客端的浏览、购物车、下单流程。
- 代码骨架来自黑马《苍穹外卖》课程。后续会加入面向校园场景的个人改动（宿舍楼自提点、按楼栋计价配送费等），改动单独开分支开发后再合并。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | JDK 21 · Spring Boot 2.7.3 · MyBatis · Maven 3.9 |
| 数据 | MySQL 9.5（库 `sky_take_out`，11 张表）· Redis（缓存章节启用） |
| 前端 | 后台管理页（Nginx 托管）· 微信小程序顾客端 |
| 部署 | 阿里云 Debian 13（计划 12 月中） |
| 协作 | git / GitHub，日常提交 |

## 目录结构

| 路径 | 职责 |
| --- | --- |
| `pom.xml` | 父工程，声明依赖版本与三个模块 |
| `sky-common/` | 公共工具：常量、异常类、JWT、对象存储与支付工具、JSON 配置 |
| `sky-pojo/` | 纯数据对象：entity 对应数据库表，DTO 为入参，VO 为出参 |
| `sky-server/` | 业务与启动：启动类、控制器、服务、数据访问、拦截器、配置 |
| `sky-server/src/main/resources/` | 应用配置与 MyBatis 的 SQL 映射文件 |
| `.gitignore` | 排除编译产物与 IDE 配置 |

## 本地运行前提

| 项 | 说明 |
| --- | --- |
| JDK 21 / Maven 3.9 | 已验证 `mvn clean compile` 构建通过 |
| MySQL 9.5 | 服务名 `MySQL95`，启动类型为手动，每次开机需手动启动 |
| 数据库 | 由课程资料的 `sky.sql` 导入后得到 `sky_take_out` 库 |
| 连接配置 | `sky-server/src/main/resources/application-dev.yml` |
| 微信开发者工具 | 顾客端联调阶段安装 |
| Redis | 缓存章节启用 |

启动入口是 `sky-server` 模块中的 `SkyApplication`，服务端口 8080。**当前阶段还不能直接启动**：Redis、对象存储、微信相关外部依赖尚未配置，需随课程进度补齐后再补本节的运行方式。

## 数据库

- `sky.sql` 只在首次搭建时导入一次；此后真正运行的是数据库里的表，数据由业务代码与后台录入产生。
- 11 张表按业务分三类：商家基础数据（分类、菜品、口味）、顾客数据（用户、地址、购物车、订单）、关系表（套餐与菜品、订单明细）。
- 其中顾客相关的表初始为空，随点单业务逐步写入。
